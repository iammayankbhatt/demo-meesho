# Meesho E-Commerce Platform ("Magic")

A fast, responsive, scalable value-focused e-commerce web platform inspired by Meesho.

## Tech Stack
- **Client**: React 19, Vite, Tailwind CSS v4, TanStack Query v5, React Router v7, Lucide React
- **Server**: Node 20+, Express 5, Supabase (Service Role), Zod, Pino
- **Database**: PostgreSQL (Supabase)

## Getting Started
1. `npm install`
2. Configure `.env` in `client/` and `server/` based on `.env.example`
3. `npm run dev`
